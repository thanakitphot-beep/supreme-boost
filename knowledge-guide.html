กลับหน้าแรกดูแพ็กเกจปัจจุบัน

ความรู้ที่ค้นกลับมาใช้ได้

คู่มือการใช้แหล่งข้อมูลของเว็บไซต์ เพื่อให้คำตอบมีที่มาและเพิ่มความรู้ได้อย่างเป็นระบบ

คู่มือนี้อธิบายความสามารถและข้อจำกัด ไม่ใช่การรับรองว่าทุกคำตอบถูกต้อง

คลังความรู้ช่วยอะไร?

คลังความรู้เก็บข้อความเกี่ยวกับธุรกิจ เช่น รายละเอียดบริการ วิธีใช้งาน และนโยบายที่เจ้าของบัญชีเพิ่มไว้ เมื่อมีคำถาม ระบบค้นข้อความที่เกี่ยวข้องแล้วส่งให้ AI ประกอบคำตอบ

เพิ่มความรู้กับฝึกโมเดลต่างกันอย่างไร?

เพิ่มความรู้คือเก็บเอกสารให้ AI ค้นอ่านตอนตอบ ส่วนการฝึกโมเดลคือปรับน้ำหนักของโมเดล การเพิ่มเอกสารใน INDICATOR ไม่ได้ฝึกน้ำหนักโมเดลและไม่รับรองว่าระบบฉลาดเทียบเท่าโมเดลใด

เพิ่มข้อมูลแบบไหนได้บ้าง?

เจ้าของบัญชีที่ได้รับอนุญาตเพิ่มข้อความโดยตรง หรือให้ระบบอ่านหน้าเว็บไซต์สาธารณะได้ ข้อความจากบทสนทนาของผู้เยี่ยมชมไม่ถือเป็นเอกสารที่เจ้าของบัญชีรับรอง

ควรเตรียมข้อมูลอย่างไร?

แยกข้อมูลตามหัวข้อ ระบุชื่อสินค้า หน่วยราคา เงื่อนไข ข้อยกเว้น และวันที่ที่ข้อมูลมีผลให้ชัดเจน ควรใช้เอกสารต้นทางของธุรกิจและตรวจความถูกต้องก่อนเพิ่มลงคลัง

เพิ่มข้อความครั้งละได้เท่าไหร่?

การเพิ่มข้อความรองรับไม่เกิน 60,000 ตัวอักษรต่อคำขอ ระบบแบ่งข้อความเป็นส่วนย่อยโดยคงข้อความต้นฉบับไว้ เอกสารที่ยาวกว่านี้ควรแยกเป็นหัวข้อก่อนเพิ่ม

อ่านเว็บไซต์หลายหน้าได้ไหม?

การอ่านเว็บไซต์หนึ่งครั้งอ่านได้สูงสุด 8 หน้าในเว็บไซต์ต้นทางเดียวกัน และรวมไม่เกิน 100 ส่วนข้อความ การอ่านอาจได้เพียงบางส่วนหากหน้าไม่พร้อมหรือใช้เวลาเกินกำหนด

อ่านหน้าเข้าสู่ระบบหรือหน้าบัญชีได้ไหม?

เครื่องมือเพิ่มความรู้จากเว็บไซต์ไม่ใช้การเข้าสู่ระบบ และปฏิเสธเส้นทางส่วนตัวที่ตรวจพบ เช่น หน้าบัญชี การชำระเงิน และแอดมิน ผู้ดูแลควรเลือกเฉพาะหน้าที่ตั้งใจเผยแพร่ให้สาธารณะอ่านได้

เว็บที่แสดงข้อมูลด้วย JavaScript อ่านได้ทั้งหมดไหม?

เครื่องมืออ่าน HTML จากเว็บไซต์โดยไม่เปิดรัน JavaScript ของหน้านั้น ข้อมูลที่แสดงเฉพาะหลังล็อกอินหรือหลังสคริปต์ทำงานอาจไม่ถูกอ่าน เจ้าของบัญชีสามารถเพิ่มข้อความต้นฉบับเองได้

ข้อมูลต่างบัญชีปะปนกันไหม?

การเก็บและค้นเอกสารของเจ้าของบัญชีกรองตามบัญชีที่ยืนยันแล้ว การเพิ่ม ดู และลบความรู้ต้องผ่านการตรวจสิทธิ์ ข้อมูลร้านตัวอย่างไม่ใช่ข้อมูลสินค้าของเว็บไซต์ลูกค้า

ปิดคอมแล้วความรู้หายไหม?

เอกสารที่บันทึกสำเร็จผ่านระบบจัดการความรู้อยู่ในฐานข้อมูลบนเซิร์ฟเวอร์ จึงไม่ต้องเปิดคอมของผู้ดูแลค้างไว้ การบันทึกยังต้องอาศัยการเชื่อมต่อฐานข้อมูลที่ทำงานอยู่

ถามภาษาไทยไม่เว้นวรรคได้ไหม?

การค้นความรู้แยกคำไทยและเชื่อมคำที่ใช้ถามใกล้เคียงกัน เช่น ค่าส่งกับการจัดส่ง จึงไม่จำเป็นต้องพิมพ์ตรงกับข้อความทุกคำ แต่ยังอาจค้นไม่เจอเมื่อคำถามกำกวมหรือแหล่งข้อมูลไม่เพียงพอ

ระบบอ่านเอกสารทั้งหมดทุกครั้งไหม?

ระบบจัดอันดับจากเอกสารของบัญชีสูงสุด 1,000 ส่วนล่าสุดต่อการค้น และคัดข้อความที่เกี่ยวข้องสูงสุด 5 ส่วนในงบ 6,000 ตัวอักษร ข้อมูลที่เก่ากว่าขอบเขตนี้อาจต้องจัดระเบียบหรือเพิ่มระบบค้นขนาดใหญ่เพิ่มเติม

คลังความรู้ช่วยประหยัดโทเค็นอย่างไร?

การเพิ่มข้อความและค้นคลังในระบบนี้ไม่จำเป็นต้องเรียกโมเดลสร้างเวกเตอร์ ระบบส่งเฉพาะข้อความที่เกี่ยวข้องให้ AI แทนการส่งเอกสารทั้งหมด แต่ขั้นตอนสร้างคำตอบด้วยโมเดลยังใช้โทเค็นและมีโควตาของผู้ให้บริการ

ถ้าไม่มีข้อมูลที่ถามจะทำอย่างไร?

ผู้ช่วยควรตอบส่วนที่มีข้อมูลรองรับและระบุส่วนที่ยังยืนยันไม่ได้ เช่น ตอบราคาที่ประกาศได้ แต่ไม่เดาจำนวนสต็อกที่ไม่มีในเอกสาร ผู้ดูแลเพิ่มหลักฐานที่ขาดได้ภายหลัง

ข้อมูลขัดแย้งกันต้องทำอย่างไร?

ผู้ดูแลควรตรวจเอกสารที่ให้ตัวเลขหรือเงื่อนไขต่างกันและแก้แหล่งข้อมูลให้ตรงกัน เอกสารที่ถูกทำเครื่องหมายว่าขัดแย้งหรือรอตรวจจะไม่ถูกเลือกโดยการค้นคลังใหม่ แต่ระบบไม่ได้ตรวจจับความขัดแย้งทุกแบบโดยอัตโนมัติ

ราคาและข้อมูลล่าสุดจะอัปเดตเองเสมอไหม?

เอกสารคือข้อมูลที่บันทึกไว้ ไม่ใช่การเชื่อมสต็อกหรือราคาแบบสด การเปลี่ยนข้อมูลต้นทางต้องนำเข้าข้อมูลใหม่และตรวจรายการเดิม การอ่านเว็บบางส่วนล้มเหลวไม่ควรถูกตีความว่าอัปเดตครบแล้ว

ดูที่มาของข้อมูลได้ไหม?

ส่วนข้อความที่ค้นได้แนบชื่อเอกสาร และ URL สาธารณะเมื่อมี เพื่อช่วยตรวจสอบคำตอบ ข้อความที่เจ้าของบัญชีเพิ่มเองอาจไม่มี URL จึงควรตั้งชื่อเอกสารให้ชัดเจน

ควรนำข้อมูลส่วนตัวหรือรหัสลับเข้าคลังไหม?

ควรนำเข้าเฉพาะข้อมูลที่ต้องการใช้ตอบผู้เยี่ยมชม ไม่ควรใส่รหัสผ่าน API key ข้อมูลบัตร หรือข้อมูลลูกค้าส่วนตัว ระบบปกปิดรูปแบบข้อมูลสำคัญที่ตรวจพบได้บางชนิด แต่ไม่ได้รับรองว่าจะพบข้อมูลส่วนตัวทุกแบบ

ถ้าเอกสารมีคำสั่งให้ AI เปลี่ยนกฎล่ะ?

เอกสารที่ค้นได้ใช้เป็นข้อมูล ไม่ใช่คำสั่งควบคุมผู้ช่วย การเพิ่มข้อความที่บอกให้เปิดเผยรหัสลับหรือข้ามสิทธิ์ไม่ได้ให้สิทธิ์แก่ระบบ ผู้ดูแลยังควรตรวจแหล่งข้อมูลก่อนใช้

คำตอบของ AI ทำรายการสำคัญทันทีไหม?

ผู้ช่วยแยกข้อเสนอการกระทำออกจากผลการทำงานจริง การนำทางต้องมีเป้าหมายที่ระบบตรวจได้ ส่วนการกระทำของปลั๊กอินขึ้นกับความสามารถและการยืนยันที่ตั้งไว้ ไม่ควรตีความข้อความว่าจะส่งต่อเป็นการยืนยันว่าเจ้าหน้าที่รับเรื่องแล้ว

ผู้ช่วยคำนวณราคาได้ไหม?

มีเครื่องมือคำนวณบวก ลบ คูณ หาร วงเล็บ และเปอร์เซ็นต์ เครื่องมือนี้คำนวณจากตัวเลขที่ได้รับ แต่ไม่ได้ยืนยันราคาหรือส่วนลดของร้าน จึงต้องใช้ร่วมกับข้อมูลราคาที่ตรวจสอบได้

ถ้าโมเดลหนึ่งติดโควตาจะเป็นอย่างไร?

ระบบลองใช้ผู้ให้บริการสำรองที่ตั้งค่าไว้ภายใต้งบเวลาและจำนวนครั้งที่กำหนด หากผู้ให้บริการทั้งหมดไม่พร้อม อาจยังตอบไม่ได้ คลังความรู้ไม่ได้ทำให้ API ใช้ได้อย่างไม่จำกัด

เพิ่มเอกสารเยอะขึ้นแปลว่าถูกต้องขึ้นเสมอไหม?

ไม่เสมอไป เอกสารซ้ำ ล้าสมัย หรือผิดอาจทำให้ค้นและตอบแย่ลง ควรเพิ่มเนื้อหาที่ขาดจริง พร้อมทดสอบคำถามที่ใช้งานบ่อยและคำถามที่ควรตอบว่ายังยืนยันไม่ได้

ระบบตอบได้ทุกคำถามหรือรับรอง 98.9% ไหม?

ยังไม่มีผลทดสอบเพียงพอรองรับคำรับรองนั้น ความสามารถขึ้นอยู่กับโมเดล เครื่องมือ แหล่งข้อมูล และงานที่ถาม ผลทดสอบชุดเล็กหรือจำนวนเอกสารไม่ใช่หลักฐานความแม่นยำในทุกสถานการณ์
