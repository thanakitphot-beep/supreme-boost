📝 About This Widget

Supreme AI is an intelligent chat widget powered by Google Gemini that:

  • Reads content from your webpage to answer customer questions
  • Supports multiple languages (Thai, English, Chinese, Japanese)
  • Allows visitors to adjust text size and theme
  • Works on any website with a single line of code

🚀 How to Embed

Copy and paste this single line of code into your website's HTML:

<script src="https://YOUR-VERCEL-DOMAIN.vercel.app/supreme-boost/boost.js" data-shop-prompt="ร้านนี้ชื่อ My Shop มีโปรส่งฟรีเมื่อซื้อครบ 1000 บาท" defer></script>
⚠️ Important: Replace YOUR-VERCEL-DOMAIN with your Vercel domain (e.g., supreme-boost-prod.vercel.app)

⚙️ Customization

You can customize the widget with these attributes:

<script src="https://YOUR-VERCEL-DOMAIN.vercel.app/supreme-boost/boost.js" data-lang="auto" data-title="Customer Support" data-shop-prompt="ร้านนี้ชื่อ ... มี..." data-primary="#2563eb" data-position="right" defer></script>
  • data-lang: Language mode (auto, th, en, zh, ja)
  • data-title: Widget title
  • data-shop-prompt: Shop info for AI context
  • data-primary: Primary color (hex or rgb)
  • data-position: Position (left or right)

📋 Features

  • ✅ Reads page content for context-aware answers
