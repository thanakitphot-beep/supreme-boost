# SaaS Plugin Setup

The Render service is the central backend. Each customer embeds the widget on
their own website using the tenant API key generated by the customer dashboard.

## Render environment variables

Set these values in the Render dashboard:

```text
NODE_ENV=production
ENFORCE_STRICT_CORS=true
REQUIRE_TENANT_API_KEY=true
ENABLE_LEGACY_HMAC_AUTH=false
INDICATOR_FILE_LEARNING=false
PUBLIC_BASE_URL=https://your-service.onrender.com
CORS_ALLOWED_ORIGINS=https://your-service.onrender.com
MONGODB_URI=<managed in Render>
JWT_SECRET=<generated in Render>
ADMIN_PASSWORD=<managed in Render>
GOOGLE_CLIENT_ID=<Google OAuth web client ID>
```

`CORS_ALLOWED_ORIGINS` is for the Render dashboard and other first-party
origins. Plugin origins are managed per tenant in the admin dashboard.

## Tenant plugin origins

Before giving a customer the embed snippet:

1. Open Admin Dashboard, select the tenant, and open General.
2. Add each website origin to Plugin Allowed Origins, one per line.
3. Save the tenant while its account status is Active.
4. Copy the generated embed code into the registered website.

Origins must be exact, for example:

```text
https://shop.example.com
https://www.shop.example.com
```

Wildcard values, paths, and query strings are rejected. The browser preflight
and the API request both verify the origin; the tenant API key cannot be used
from another tenant's registered website.

## Google Sign-In

1. In Google Cloud Console, create an OAuth 2.0 Client ID of type Web
   application.
2. Add the customer dashboard URL as an Authorized JavaScript origin, for
   example `https://your-service.onrender.com`.
3. Copy the Client ID, not a client secret, into Render as `GOOGLE_CLIENT_ID`.
4. Redeploy Render and open `/customer-login` to confirm the Google button
   appears.

Google ID tokens are verified on the server. With `REGISTRATION_MODE=disabled`,
only an existing linked identity can sign in and no new tenant is created. An
existing password account is never linked only by matching email; linking
requires an authenticated account-ownership flow.
